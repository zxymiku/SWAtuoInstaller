# 安全与逻辑审查

审查范围：Tauri 命令层、下载器、归档/ISO 流程、外部进程调用、临时目录和前端配置表单。

## 已修复

- ISO 挂载命令返回非零退出码时，之前可能继续执行；现在必须成功退出且解析到有效结果。
- 远端文件长度变化时，旧的断点位图会被清空并重新下载，避免把旧文件和新文件混合。
- 未配置校验值时不再把缓存目录中唯一的任意文件当作当前压缩包。
- 远程配置限制为带主机名的 HTTPS，并限制为 4 MiB；7z 自动下载限制为 HTTPS 和 32 MiB，并检查 `MZ` 文件头。
- 下载器的断点状态已移到独立模块，配置面板已拆为导航、字段和安全/7z 字段组件。
- 环境检测展示实际工作目录，避免界面显示的临时目录与执行目录不一致。
- 应用启动即创建应用数据目录 `logs/session-时间.log`；启动、配置加载、界面按钮、对话框取消、安装步骤和错误均追加到同一会话日志，日志行包含当前步骤和错误分类，下载线程不再绕过持久化日志出口。

## 仍需使用者确认的风险

- 安装流程会执行介质中的 `.reg`、`server_*.bat` 和第三方安装器；这些文件必须来自可信来源。
- `antivirus.remove_defender`、第三方 `uninstall`、网络禁用和进程强杀都可能改变系统状态，默认或自定义配置应在隔离环境验证。
- 未填写 SHA-256 时只能验证下载流程和文件长度，不能证明内容来自预期发布者。
- ISO/安装器/补丁的实际目录结构因发行介质而异，未持有同一版本介质时无法替代现场验证。
